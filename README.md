# 顺诚AI工作平台

美客多跨境电商（顺诚）内部工作平台。

现有板块：
- **选品中心** —— 日用百货四大场景品类（内容待填充）
- **店铺矩阵** —— 18 家店的健康与风险对照（**已接入真实数据**）

线上地址：https://lingkongwangyuan.github.io/shuncheng-platform/

七个页面都是 30 行左右的薄壳，只负责声明「我是哪一页」：

```html
<body data-page="shops">
  <div id="sc-header"></div>     <!-- layout.js 注入 -->
  <div id="sc-sidebar"></div>    <!-- layout.js 注入 -->
  <main class="main"><div id="sc-content"></div></main>  <!-- 对应 render 脚本注入 -->
</body>
```

## 怎么改（不用碰页面）

| 想改什么 | 改哪里 |
|---|---|
| 加 / 删品类、改品类文案、改三级细分品类 | `data/categories.js` 的 `categories` |
| 改左侧导航（栏目、子项、顺序） | `data/categories.js` 的 `nav` |
| 改 AI 智能体清单 | `data/categories.js` 的 `agents` |
| 改某个页面的版式、颜色、间距 | `assets/theme.css` |
| 改选品中心的区块结构 | `assets/render.js` |
| 改店铺矩阵的区块结构 | `assets/render-shops.js` |
| **更新店铺数据** | 重新跑数据脚本（见下节），**不要手改 `data/shops.js`** |

**加一个新品类的完整步骤：**

1. 在 `data/categories.js` 的 `categories` 数组里加一条（参考现有条目字段）
2. 复制任一品类页（如 `kitchen.html`），改 `data-page` 为新的 `id`
3. 在 `nav` 的选品中心 `children` 里加一行，`page` 指向新文件
4. 完成——导航高亮、面包屑、统计数字全自动

## 店铺矩阵（已接入真实数据）

数据来源：`数据底座/顺诚经营数据底座.xlsx` —— 3,827 条店铺日报，2026-07-01 ~ 09-19，18 家店 × 5 站点。

**更新数据只跑一条命令**（在项目根目录 `顺诚-美客多/` 下执行）：

```bash
python scripts/10_build_shopmatrix.py
```

脚本重新生成 `data/shops.js`，页面即刻生效。**不要手改 `data/shops.js`。**

### 三个计算口径（改动前请确认）

| 指标 | 算法 | 为什么这么算 |
|---|---|---|
| 色级风险率 | 红橙黄记录数 ÷ **有色级记录数** | 分母排除「未标注」，两名管理人才可比 |
| 未标注率 | 未标注记录数 ÷ 总记录数 | 单独成列，**不参与健康评分**；未标注 ≠ 健康 |
| 封停/30天 | 封停次数 ÷ 覆盖天数 × 30 | 各店记录天数差 5 倍（13 ~ 60 天），必须归一化 |

### 两个页面

| 页面 | 内容 |
|---|---|
| `shops.html` | 18 家店对照表，按「封停/30天」降序（最该管的排最前），支持按管理人筛选 |
| `shops-group.html` | 管理人对比（色级 vs 封停双轴）、站点风险分布、月度趋势、风险类型聚集、最近风险事件 |

### 已知数据问题（脚本只标注、不改数）

- **李彦辉出单口径存疑**：转化 7.23%，为所有店中位数的 6.9 倍，页面标「出单口径待核」
- **两名管理人截止日期不同**：石老师 09-18、李源 09-19，页面按各店实际日期展示
- **色级标注习惯不同**：李源 100% 标注，石老师 32% 未标注 —— 看风险率时务必同时看未标注率

## 配色铁律（改样式必须遵守）

1. **同色系禁止**：背景与文字不得同色相（浅橙底绝不配橙字）
2. **浅亮底**（相对亮度 > 0.85）文字对比度须 ≥ 4.5:1
3. **彩色浅底配深色字，深色实底才配白字**

改动样式后必须跑门禁：

```bash
python _tools/check_contrast.py
# 退出码 0 才可交付
```

该脚本会先把 `assets/theme.css` 内联，再调用对比度自检。会**自动扫描根目录下所有页面**（`_` 开头的临时文件除外），新增页面无需改脚本。
